# Security Policy

## Reporting a Vulnerability

Please do not file public issues on GitHub for security vulnerabilities.
All security vulnerabilities should be reported to Circle privately, through
Circle's [Bug Bounty Program](https://hackerone.com/circle-bbp).
Please read through the program policy before submitting a report.

## Scope

This repository contains upstream [reth](https://github.com/paradigmxyz/reth)
releases with backported upstream fixes.

- Report a vulnerability in a backport, or one that affects Arc, to Circle, as
  described above.
- Report a vulnerability in upstream reth code to the reth maintainers, as
  described in the [reth security policy](https://github.com/paradigmxyz/reth/security/policy).
